# Flores Amarillas para Judith 🌻💛

Un universo cósmico 3D interactivo creado especialmente con mucho cariño para **Judith**.

Inspirado en la galaxia de flores amarillas con un anillo celestial luminoso, girasoles flotantes, mensajes de afecto y la canción *"Mi Persona Favorita"* de **Río Roma** (*"Fue un día como cualquiera nunca olvidaré la fecha..."*).

## ✨ Características
- **Galaxia 3D Interactiva**: Desarrollada con Three.js y controles de órbita para explorar el universo en 360°.
- **Anillo Celestial & Agujero Negro Dorado**: Efecto de brillo neón idéntico al estilo viral de redes.
- **Girasoles y Ramos en Órbita**: Flores flotando a diferentes profundidades y alturas.
- **Frases Luminosas**: Mensajes románticos dedicados a Judith en el espacio.
- **Música Integrada**: Canción *"Mi Persona Favorita"* de Río Roma con controles y ecualizador animado.
- **Carta Especial**: Modal desplegable con dedicatoria romántica.

## 🚀 Uso
Simplemente abre `index.html` en cualquier navegador web moderno.
